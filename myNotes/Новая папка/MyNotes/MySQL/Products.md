## 🔹 Шаг 3. Операции выборки и множеств

Были отработаны базовые операции реляционной алгебры:
*   **WHERE:** фильтрация строк (товары дороже 150).
*   **PROJECTION:** выбор только определенных столбцов (`SELECT name`).
*   **UNION:** объединение списков товаров из двух таблиц (без дубликатов).
*   **EXCEPT:** поиск разности (товары, которые есть в первой таблице, но отсутствуют во второй).
*   **INTERSECT:** поиск пересечения (товары, которые есть в обеих таблицах).

## 🔹 Шаг 4. Операции соединения (JOIN)

Были выполнены операции соединения таблиц:
*   **CROSS JOIN (Декартово произведение):** выдал 16 строк (все возможные комбинации товаров друг с другом).
*   **INNER JOIN:** выдал 2 строки (только те товары, которые есть в обеих таблицах с одинаковой ценой).
*   **LEFT JOIN:** выдал 4 строки (показал все товары из первой таблицы, а для тех, которых нет во второй, поставил `NULL`).
